## Conhecimentos prévios

Fundamentos para trabalhar com dados; estatística e probabilidade; introdução à análise de dados; Python básico; SQL e bancos de dados; Python para análise. A imagem informa a sequência, não garante domínio uniforme da turma.

## Exigências de material

- **Formato definido pelo professor: somente HTML autocontido e interativo.** O e-mail original solicitava PowerPoint, mas o professor definiu que usará apenas HTML. `Template ONS.pptx` é a referência visual e fonte de ativos, não um formato de saída.
- Leituras complementares: links ou referências no último slide.
- Vídeos: fonte indicada; não usar vídeos de emissoras de TV, conforme alinhamento do Pecege.
- Interação por Wooclap: enquetes, nuvens de palavras, perguntas abertas; grupos também são possíveis.

## Datasets definidos pelo curso

1. https://dados.ons.org.br/dataset/balanco-energia-subsistema
2. https://dados.ons.org.br/dataset/curva-carga

Usar esses dois conjuntos como fio condutor. Ler os dicionários, conferir unidade, cobertura, granularidade e chaves antes de combinar. Registrar URL e versão/data de extração em cada análise: o ONS informa que dados podem ser revisados depois da publicação. Não presumir equivalência entre as medidas de carga das duas bases. Exemplos simulados devem ser identificados; problemas inseridos para exercícios não são defeitos atribuídos à base oficial.
