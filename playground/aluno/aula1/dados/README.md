# Respostas salvas da Open-Meteo

`clima_<subsistema>.json` são respostas da API Historical Weather (`/v1/archive`) para 01 a 07/01/2025, `hourly=temperature_2m`, `timezone=America/Sao_Paulo`, uma cidade por subsistema: Belém (N), Recife (NE), São Paulo (SE) e Porto Alegre (S). Obtidas em 18/10/2026 com `aluno/aula1/extrair_clima.py`. Servem para trabalhar sem internet e para a fonte `ClimaArquivo` da demonstração.

[Weather data by Open-Meteo.com](https://open-meteo.com/), licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

- Zippenfenig, P. (2023). *Open-Meteo.com Weather API* [Computer software]. Zenodo. https://doi.org/10.5281/ZENODO.7970649
- Hersbach, H., Bell, B., Berrisford, P., et al. (2023). *ERA5 hourly data on single levels from 1940 to present* [Data set]. ECMWF. https://doi.org/10.24381/cds.adbb2d47
